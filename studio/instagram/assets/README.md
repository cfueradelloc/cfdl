# Material gráfico

Zona de descarga manual. Nada de esto se baja solo.

- `retratos/` — retratos de autoras y autores.
- `portadas/` — portadas de libros.

El original vive en el Drive del colectivo, en `Eventos/<ciclo>/<autor>/`; el mapa completo
está en `content/SOURCES.md`. Cópialos a mano: el módulo no habla con Drive.

Antes de publicar un retrato, comprueba que el colectivo tiene derecho a hacerlo.

Las fotos ya publicadas en `docs/gallery/` se pueden referenciar directamente desde un
brief con `../../../docs/gallery/<archivo>.jpg`, sin copiar nada.
