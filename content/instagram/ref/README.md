# Referencias

Capturas del perfil real de [@cfueradelloc](https://www.instagram.com/cfueradelloc/).
**Entrada, no salida**: aquí no escribe nada el generador.

El perfil exige inicio de sesión, así que no se puede leer desde el repo (ver la nota
«Pendiente» en `content/SOURCES.md`). Las plantillas de `content/instagram/` se dedujeron
de los carteles del Drive, de `docs/assets/css/base.css` y de las reglas de voz de
`CLAUDE.md` — no de las publicaciones reales.

Deja aquí unas cuantas publicaciones representativas y se ajusta `src/_shared.css` contra
ellas: retícula, escala, encuadres y estilo de pie de foto.
