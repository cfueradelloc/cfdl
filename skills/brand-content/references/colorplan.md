## CFDL Active Subset — as shipped on the live site

**The source of truth is `content/paleta/`, not this file.** Run `python3 paleta.py` for
the current values and `--verificar` to check the contrasts. What follows is a copy for
reading, and copies go stale — the tokens below are generated by `paleta.py --css`.

```css
:root {
    --bg:        #fdf5eb; /* papel   — page background                */
    --surface:   #f1e7db; /* hueso   — sidebars / cards               */
    --text:      #171513; /* tinta   — body text                      */
    --muted:     #6a625a; /* humo    — secondary text on light ground */
    --border:    #e0d6ca; /* filete  — borders, dividers              */
    --rule:      #e0d6ca; /* filete  — hairlines                      */
    --accent:    #ffb923; /* ámbar   — fills, large marks             */
    --accent-fg: #714a00; /* ámbar darkened — accent as text or focus */
    --band-bg:   #332f8a; /* zafiro  — header, footer, dark bands     */
    --band-fg:   #fff4d6; /* cera    — light ink on the band          */
}
```

The **manifiesto** page inverts this (zafiro ground, cera text). On the zafiro dark bands
secondary text is `#bbabd5` (lavanda, 5.17:1). The shared implementation lives in
`docs/assets/css/base.css` (tokens + `body.theme-dark`) and `docs/assets/css/viewer.css`.

### The Colorplan table above is paper, not screen

Those 48 swatches approximate GF Smith papers and **none of them is a shipped value**.
Where a name appears in both places the hex differs, sometimes a lot: Candy Pink is
`#e2bdc4` on paper and `#f8ccce` on screen; Sapphire `#445d87` against `#332f8a`;
Amethyst `#3c3048` against the `#8c82c3` the t-shirts use. Reach for the table when
specifying printed stock, never when writing CSS.

> **Correction.** An earlier version of this file said the amber palette built on
> `#ffb923` was «not shipped». That was false when written and is plainly false now: the
> amber is the logo's own colour, it was already carrying marca, Instagram and the
> t-shirts across some three thousand occurrences, and since the palette was unified it is
> the site's accent too. Earlier docs also listed a muted paper subset (Mist / Ebony /
> Citrine) — that one really is gone.
